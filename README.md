## GS006/GS003 Introduction to GeoServer
This repo contains the necessary files and configurations for setting up the training environment for Gispo's GeoServer courses in AWS.

The English course is called Introduction to GeoServer and the Finnish one Johdanto GeoServerin käyttöön. Both courses use this repo for setting up the training environment.

This repo does not contain any exercises, they reside in the master-training-data in folders [GS006](https://github.com/GispoCoding/master-training-data/tree/main/src/GS006) and [GS006_eng](https://github.com/GispoCoding/master-training-data/tree/main/src/GS006). For the course that uses GeoServer version 3 you'll find the exercises in the folder [GS003](https://github.com/GispoCoding/master-training-data/tree/main/src/GS003)
